# 🏎️ 드리프트 러시 온라인 (Drift Rush Online)

친구들과 최대 8명이 같은 트랙에서 실시간으로 달리는 브라우저 카트 레이싱 게임입니다.
레이스는 항상 8대로 출발하고, 사람이 모자란 자리는 컴퓨터가 채웁니다.

## 이렇게 놀아요

1. 한 명이 **같이 달리기** 탭에서 이름을 적고 **방 만들기**를 누릅니다.
2. 대기실에 나온 4자리 **방 코드**를 친구들에게 알려줍니다. **초대 링크 복사**를 눌러 링크를 보내도 됩니다.
3. 친구들은 같은 사이트에 들어와 방 코드를 입력하고 **참가**를 누릅니다.
4. 모두 모이면 방장이 바퀴 수와 컴퓨터 실력을 정하고 **레이스 시작**을 누릅니다.
5. 끝나면 순위대로 포인트를 받고, **대기실로**를 눌러 다음 판을 준비합니다.

- 방장이 레이스 도중에 나가면 다음 사람이 자동으로 방장이 됩니다.
- 레이스 도중에 나간 사람의 카트는 컴퓨터가 이어서 달립니다.
- 레이스 중에 들어온 친구는 대기실에서 기다렸다가 다음 판부터 같이 달립니다.
- 첫 번째 사람이 결승선을 통과하면, 나머지 사람에게 60초가 주어집니다. 그 안에 못 들어오면 미완주 처리되고 포인트는 절반만 받습니다.

혼자 달리기와 차고(카트 상점)도 그대로 있습니다. 포인트와 보유 카트는 각자의 브라우저에 저장됩니다.

## 조작법

| 키 | 동작 |
|---|---|
| `↑` `↓` (또는 `W` `S`) | 가속 · 브레이크 |
| `←` `→` (또는 `A` `D`) | 방향 |
| `Shift` | 드리프트 시작, 한 번 더 누르면 종료 (방향키와 함께) |
| `Space` | 부스터 사용 |
| `R` | 트랙 가운데로 복귀 |
| `M` | 소리 켜기 · 끄기 |
| `Esc` | 나가기 |

휴대폰에서는 자동으로 가속되고, 화면 버튼으로 조작합니다.

## Render에 올리는 방법

준비물은 GitHub 계정과 Render 계정, 두 가지입니다. Render는 GitHub 계정으로 바로 가입할 수 있습니다.

### 1단계: GitHub에 올리기

1. GitHub에서 **New repository**를 눌러 `drift-rush-online` 같은 이름으로 저장소를 만듭니다.
2. **uploading an existing file**을 누르고, 이 폴더 안의 파일과 폴더를 전부 끌어다 놓습니다.
   - 올려야 하는 것: `server.js`, `package.json`, `render.yaml`, `README.md`, `.gitignore`, `public` 폴더
   - `node_modules` 폴더가 있다면 올리지 마세요. Render가 알아서 설치합니다.
3. **Commit changes**를 누릅니다.

### 2단계: Render에서 서버 만들기

1. [render.com](https://render.com)에 로그인하고 대시보드에서 **New** → **Web Service**를 선택합니다.
2. GitHub를 연결하고, 방금 만든 `drift-rush-online` 저장소를 고릅니다.
3. 설정 화면에서 아래처럼 입력합니다.

   | 항목 | 값 |
   |---|---|
   | Name | `drift-rush` (원하는 이름. 사이트 주소가 됩니다) |
   | Region | **Singapore** (한국에서 가장 가까워서 지연이 적습니다) |
   | Branch | `main` |
   | Runtime | Node |
   | Build Command | `npm install` |
   | Start Command | `npm start` |
   | Instance Type | **Free** |

4. **Deploy Web Service**를 누르고 몇 분 기다립니다. 로그에 `Drift Rush server listening`이 보이면 완료입니다.
5. 화면 위쪽의 `https://drift-rush.onrender.com` 같은 주소를 친구들에게 공유하면 끝입니다.

> 저장소에 `render.yaml`이 들어 있어서, **New** → **Blueprint**를 골라도 위 설정이 자동으로 채워집니다.

### 코드를 고치면

GitHub 저장소의 파일을 수정해서 Commit하면, Render가 알아서 다시 배포합니다.

## 무료 요금제에서 알아둘 점

- **잠들기:** 15분 동안 아무도 접속하지 않으면 서버가 잠듭니다. 다음에 처음 들어가는 사람은 서버가 깨어날 때까지 1분쯤 기다려야 합니다. 같이 노는 동안에는 잠들지 않습니다.
- **사용 시간:** 한 달에 750시간까지 무료입니다. 서버 하나를 한 달 내내 켜둬도 충분합니다.
- **재시작:** Render가 가끔 서버를 재시작할 수 있습니다. 그러면 열려 있던 방이 사라지니, 새로 방을 만들면 됩니다.

## 파일 구조

```
drift-rush-online/
├── server.js          # 게임 파일 제공 + 방 관리 + 실시간 위치 중계
├── package.json       # Node.js 설정 (ws 라이브러리 사용)
├── render.yaml        # Render 자동 설정 (Blueprint용)
└── public/            # 브라우저에서 실행되는 게임
    ├── index.html
    ├── css/style.css
    ├── js/game.js
    └── favicon.svg
```

## 동작 방식

- 각자의 브라우저가 자기 카트의 물리를 계산하고, 1초에 20번 위치를 서버로 보냅니다.
- 서버는 받은 위치를 같은 방의 다른 사람들에게 전달합니다.
- 컴퓨터 카트는 방장의 브라우저가 계산해서 다른 사람들에게 보냅니다.
- 받은 쪽은 위치 사이를 부드럽게 이어서 그리기 때문에, 친구 카트가 순간이동하지 않고 자연스럽게 움직입니다.

## 내 컴퓨터에서 실행해보기

[Node.js](https://nodejs.org) 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`에 접속하면 됩니다. 같은 와이파이에 있는 친구는 `http://내컴퓨터IP:3000`으로 들어올 수 있습니다.

## 직접 손보기

- **한 방 최대 인원:** `server.js`의 `MAX_PLAYERS`
- **컴퓨터 이름과 카트:** `server.js`의 `AI_NAMES`, `AI_KARTS`
- **카트 가격과 성능:** `public/js/game.js`의 `KARTS`, `EXT`
- **순위별 포인트:** `public/js/game.js`의 `RANK_P`
- **최고 속도 등 물리:** `public/js/game.js`의 `const ACCEL=30,MAXV=58,...`

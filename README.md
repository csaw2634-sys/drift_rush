# 🏎️ 드리프트 러시 (Drift Rush)

코너에서는 드리프트로 게이지를 채우고, 직선에서는 부스터로 질주하는 브라우저 카트 레이싱 게임입니다.
설치할 필요 없이 링크만 열면 PC와 휴대폰에서 바로 플레이할 수 있습니다.

## 게임 소개

- 4차선 서킷에서 AI 카트 3대와 레이스를 벌입니다.
- 드리프트로 게이지를 채우면 부스터가 생기고, 최대 2개까지 모을 수 있습니다.
- 완주 순위에 따라 포인트를 받고, 차고에서 더 좋은 카트를 살 수 있습니다.
- 비싼 카트일수록 최고 속도, 가속, 핸들링, 드리프트 충전, 드리프트 탈출 성능이 좋습니다.

## 조작법

| 키 | 동작 |
|---|---|
| `↑` `↓` (또는 `W` `S`) | 가속 · 브레이크 |
| `←` `→` (또는 `A` `D`) | 방향 |
| `Shift` | 드리프트 시작, 한 번 더 누르면 종료 (방향키와 함께) |
| `Space` | 부스터 사용 |
| `R` | 트랙 가운데로 복귀 |
| `M` | 소리 켜기 · 끄기 |
| `Esc` | 처음 화면으로 |

휴대폰에서는 자동으로 가속되고, 화면 버튼으로 방향, 드리프트, 부스터, 브레이크를 조작합니다.

## 포인트 규칙

바퀴당 1위 100P, 2위 70P, 3위 45P, 4위 25P를 받습니다.
상대 실력에 따라 배율이 붙습니다. 느긋하게는 ×0.8, 보통은 ×1, 빡세게는 ×1.3입니다.

포인트와 보유 카트, 최고 기록은 각자의 브라우저에 저장됩니다. 그래서 친구마다 따로 모으게 됩니다.

## 친구들과 함께 플레이하기 (GitHub Pages로 배포)

이 저장소를 GitHub Pages로 배포하면 `https://아이디.github.io/drift-rush/` 같은 주소가 생깁니다. 이 주소를 친구들에게 공유하면 누구나 바로 플레이할 수 있습니다.

1. GitHub에 로그인한 뒤 오른쪽 위 **+** 버튼을 누르고 **New repository**를 선택합니다.
2. Repository name에 `drift-rush`를 입력하고, **Public**을 선택한 다음 **Create repository**를 누릅니다.
3. 새로 생긴 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 이 폴더 안의 파일과 폴더(`index.html`, `css`, `js`, `favicon.svg`, `README.md`, `.nojekyll`)를 전부 끌어다 놓고 **Commit changes**를 누릅니다.
   - 폴더째 끌어다 놓으면 `css/style.css`, `js/game.js` 구조가 그대로 유지됩니다.
   - `.nojekyll`은 숨김 파일이라 안 보일 수 있습니다. 빠져도 게임은 정상 작동합니다.
5. 저장소의 **Settings** → 왼쪽 메뉴 **Pages**로 이동합니다.
6. **Build and deployment**의 Source를 **Deploy from a branch**로 두고, Branch를 `main` / `/ (root)`로 선택한 뒤 **Save**를 누릅니다.
7. 1~2분 기다린 뒤 Pages 화면을 새로고침하면 위쪽에 사이트 주소가 표시됩니다. 이 주소를 친구들에게 보내면 끝입니다.

### 친구와 같이 수정하고 싶다면

저장소의 **Settings** → **Collaborators**에서 친구의 GitHub 아이디를 초대하면, 친구도 파일을 고칠 수 있습니다.
`main` 브랜치에 변경이 올라가면 1~2분 안에 사이트에 자동으로 반영됩니다.

## 내 컴퓨터에서 실행하기

`index.html`을 더블클릭해서 브라우저로 열어도 됩니다.
브라우저 보안 설정 때문에 잘 안 열리면, 이 폴더에서 아래 명령으로 간단한 서버를 띄운 뒤 `http://localhost:8000`에 접속하세요.

```bash
python -m http.server 8000
```

## 파일 구조

```
drift-rush/
├── index.html      # 화면 구조 (메뉴, HUD, 결과 화면)
├── css/style.css   # 디자인
├── js/game.js      # 게임 로직 (트랙, 물리, AI, 상점)
├── favicon.svg     # 사이트 아이콘
└── .nojekyll       # GitHub Pages가 파일을 그대로 쓰도록 하는 설정
```

## 직접 손보기

`js/game.js`에서 아래 값들을 바꾸면 게임 밸런스를 조절할 수 있습니다.

- **카트 목록과 가격, 성능:** `const KARTS=[...]`
  - `st`의 `spd`(최고 속도), `acc`(가속), `hnd`(핸들링), `chg`(드리프트 충전)는 1.0이 기본값입니다.
- **드리프트 탈출 성능:** `const EXT={...}`
  - 1.0은 0.30초 동안 미끄럼 속도의 20%를 가속으로 바꾸고, 1.3은 0.85초 동안 70%를 바꿉니다.
- **순위별 포인트:** `const RANK_P=[100,70,45,25];`
- **상대 실력:** `const DIFF=[...]`
  - `m`은 AI 속도, `bonus`는 포인트 배율입니다.
- **기본 물리:** `const ACCEL=30,MAXV=58,...`
  - `MAXV`는 최고 속도로, 58이 209km/h입니다.
- **트랙 모양:** `const CTRL_BASE=[...]`
  - 트랙을 이루는 기준점 좌표입니다. `MAP_SCALE`로 전체 크기를 바꿀 수 있습니다.

## 사용 기술

- [three.js](https://threejs.org/) r128 (CDN으로 불러옴)
- 순수 HTML, CSS, JavaScript만 사용해서 빌드 과정이 필요 없습니다.
- 소리는 Web Audio API로 직접 만듭니다.
